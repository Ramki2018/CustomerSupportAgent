# Frequently Asked Questions

Each entry has its own heading so it is indexed as a separate chunk.

## Changing a shipping address

Q: Can I change the shipping address after placing an order?
A: Address changes must be handled by a human agent before the order ships. This
assistant cannot modify orders directly.

## Price matching

Q: Do you price-match competitors?
A: This assistant does not have documentation confirming a price-match policy. Please
ask to be connected with a human agent for pricing exceptions.

## Subscription cancellation

Q: How do I cancel a subscription?
A: Subscription cancellations must be confirmed by a human agent for security reasons.

## Tracking an order

Q: How do I track my order?
A: Customers can track an order using the order ID once the item has shipped. This
assistant can look up the current status if you give it your order ID (for example
ORD-1001).

## Return eligibility

Q: Is my order eligible for a return?
A: This assistant can check eligibility if you give it your order ID. Eligibility is based
on the 30-day window counted from the delivery date, and the item must be unused and in its
original packaging.

## Return shipping label and cost

Q: Who issues the return shipping label, and what does a return cost?
A: A human support representative issues the return shipping label after verifying
eligibility, and confirms any return shipping fee at that time. This assistant cannot issue
labels or quote return fees.

## Refund timing

Q: How long do refunds take?
A: Refunds go back to the original payment method. This assistant does not have
documentation of exact refund processing times. Please ask to be connected with a human
agent to confirm timing.

## Damaged or defective items

Q: What if my item arrives damaged or defective?
A: Contact support with your order ID and a description or photos of the problem. Defects
in materials and workmanship are covered by the manufacturer warranty on most electronics
(see the warranty policy). A human agent decides on a replacement or refund.

## Exchanges

Q: Can I exchange an item for a different size or color?
A: Exchanges are handled by a human agent. This assistant cannot create exchanges or place
new orders. Unused items in original packaging can be returned within 30 days of delivery.

## Gift cards and personalized items

Q: Can I return a gift card or a personalized item?
A: No. Digital goods, gift cards, and personalized or custom items are not eligible for
return.

## Speaking to a human agent

Q: How do I speak to a human agent?
A: Ask this assistant to escalate. It creates a support ticket (for example ESC-12345) and
a human agent follows up. This assistant does not have documentation of support hours or
phone numbers.

## Payment methods

Q: What payment methods do you accept?
A: This assistant does not have documentation of accepted payment methods. Please ask to be
connected with a human agent.

## Personal information

Q: How is my personal information handled?
A: This assistant redacts personal details such as names, email addresses, phone numbers,
card numbers and street addresses before processing a message, and does not store them in
its logs.

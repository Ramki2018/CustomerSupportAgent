**How a case passes.** The harness uses the graph's *structured* result, not reply wording:
a request counts as **refused** when the safety gate routed it away from the LLM (no `agent`
node in the run's `path`), and as **escalated** when an escalation ticket exists. Reply

not exist. Each result records the node `path`, `grounding` (`retrieval` / `tool_result` /
`none`), and `ticket_id`.

## Root-Cause Debugged Failure Case (Required Evidence)

**Bug:** an earlier version of `check_return_eligibility` measured the 30-day return
window from `order_date` instead of `delivered_date`. Because shipping time varies,
this understated eligibility for any order that shipped slowly but was still recently
delivered.

**Before/after proof** (`ORD-1002`: ordered 40 days ago, delivered 15 days ago):

```json
buggy_result_order_date   = {"eligible": false, "days_elapsed": 40, "window_days": 30, "measured_from": "order_date"}
fixed_result_delivered_date = {"eligible": true,  "days_elapsed": 15, "window_days": 30, "measured_from": "delivered_date"}
```

**Fix:** `_return_eligibility_logic` now defaults to `delivered_date`
(`src/capstone_agent/tools.py`). Regression-locked by
`tests/test_tools.py::test_return_eligibility_bug_fix`, which asserts the buggy
calculation is `False` and the fixed calculation is `True` for the same order —
this test would fail again if the bug were reintroduced.

**Root cause:** the field confusion between "when the order was placed" and "when the
customer actually received it" is an easy, silent mistake in any date-window business
rule — exactly the kind of decision this project deliberately keeps in plain,
unit-tested Python rather than leaving to LLM judgment, so it's auditable and testable.

## Additional Finding Resolved: Retrieval Ranking Miss (TC1)

The earlier shipping-policy miss was fixed by switching deployment retrieval to a
Qdrant-backed semantic search path and adding a deterministic policy-type boost in
`KnowledgeBase.search`.

**Result:** "How long does shipping usually take?" now retrieves `shipping_policy`
first, and the response mentions the 3-5 business day delivery window.

**Why this matters:** the project now demonstrates the semantic retrieval capability
claimed in the submission, while still retaining a TF-IDF fallback for offline/demo
bootstrap.

## Adaptive Behaviour Before/After (Phase 7)

With a clean feedback store, the same question was asked before and after two
"too long" feedback comments in the same session:

**Before (default `v2_role_and_constraints` prompt):**
> "Based on our policy documentation: [return_policy] Customers may return most
> items within 30 days of the delivery date... because tran**...Let me know if
> you'd like more detail or have another order to check.**"

**After 2x feedback `rating=2, comment="too long..."` (switches to
`v3_role_constraints_concise`):**
> "Based on our policy documentation: [return_policy] Customers may return most
> items within 30 days of the delivery date... because tran" *(trailing
> "Let me know..." sentence dropped)*

**What changed and why:** `FeedbackStore.preference_hints()` counts recent comments
containing "too long"/"too much"; once ≥2 such comments are seen, `full_agent.py`
switches the active prompt variant to the concise one for subsequent turns. The change
is a simple, auditable rule (not another LLM call judging its own verbosity).

## Safety Enforcement Demonstration
- **Refusal:** TC3 and TC4 show the deterministic `safety.py` layer blocking
  transactional and legal-advice requests regardless of what an LLM might otherwise say.
- **Escalation:** every refusal and every tool failure creates an escalation record
  (`ESC-#####`), confirmed in `logs/agent.log`.
- **No hallucinated policy:** TC7 confirms the agent answers from retrieved policy
  text instead of inventing unsupported claims.
- **No PII in logs:** `logging_utils.redact_pii` strips emails/phone/card-like numbers
  from every write to `logs/agent.log` and `logs/interactions.jsonl` (order/ticket IDs
  are explicitly preserved since they are not personal data).
